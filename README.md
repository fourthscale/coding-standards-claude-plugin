# coding-standards-claude-plugin

A Claude Code plugin that enforces your project's coding rules while developers
work — with **zero token cost and no network**.

It does two things:

- **Prevention** — the plugin's `CLAUDE.md` imports the project's composed rules
  (`.claude/coding-rules.md`) so Claude Code has them in context from the start.
- **Guarantee** — a `Stop` hook forces one review pass before Claude Code finishes
  a task: it reads the same composed rules, and if code was changed it blocks and
  asks Claude to re-check and fix. Anti-loop via `stop_hook_active` (fires once
  per task, never loops).

This plugin ships **no rules of its own**. The rules come from the consumer
project's `.claude/coding-rules.md`, generated by the
[coding-standards-engine](https://github.com/fourthscale/coding-standards-engine)
resolver from the project's `coding-rules.config.yml`.

## Install

```
/plugin marketplace add git@github.com:fourthscale/coding-standards-claude-plugin.git
/plugin install coding-standards@fourthscale-standards
```

The repo is its own marketplace: `.claude-plugin/marketplace.json` lists the
plugin with `source: "./"` (the plugin lives at the repo root).

## What the developer needs in their project

1. This plugin installed.
2. A `coding-rules.config.yml` and a generated `.claude/coding-rules.md`
   (produced by `npx coding-rules-resolve` from **coding-standards-engine**).
3. Their project `CLAUDE.md` importing `@.claude/coding-rules.md`.

If `.claude/coding-rules.md` is missing, the hook and `/review` tell the dev to
run `npx coding-rules-resolve` first.

## Layout

```
.
├── .claude-plugin/
│   ├── plugin.json         the plugin manifest
│   └── marketplace.json    catalog (source: "./")
├── CLAUDE.md               rules in context + mandatory-review instruction
├── commands/review.md      /review — manual review against the composed rules
├── hooks/hooks.json        wires the Stop hook
└── scripts/
    └── stop-review-hook.mjs  the guardrail (no token, no network, no deps)
```

## Contents

- **`/review`** — re-reads changed files against `.claude/coding-rules.md` and
  fixes major/critical violations.
- **Stop hook** — guarantees that review runs before a task ends.

## Versioning

Bump `version` in both `.claude-plugin/plugin.json` and the entry in
`.claude-plugin/marketplace.json`, commit, tag, push. Developers update with
`/plugin marketplace update`.
